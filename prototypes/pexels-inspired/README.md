# Danbooru · Pexels 风格设计原型

参考 [Pexels 中文首页](https://www.pexels.com/zh-cn/) 的白底、宽搜索框、专题入口与图片优先布局，为现有 Danbooru 项目制作的独立设计原型。

## 打开

在仓库根目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，访问：

http://127.0.0.1:4173/prototypes/pexels-inspired/

也可直接打开本目录的 `index.html`。无构建依赖、外部字体或网络图片。

## 可体验的交互

- 标签搜索：多个标签以空格分隔，取交集；支持 `-ocean` 等排除标签及风景、天空、海边、夜色等中文别名。
- 专题与推荐标签：点击后筛选示例作品。
- 评级、横竖比例、排序，以及无结果提示和清除筛选。
- 收藏与取消收藏、收藏视图和空状态。
- 大图预览、上一张/下一张、键盘方向键、Esc 关闭，以及预览标签反查。
- 舒适/紧凑布局、标题显示开关、本地保存偏好。
- 根据屏幕宽度调整瀑布流列数，遵循系统减少动态效果偏好。

## 示例数据

12 幅原创 SVG 风景示意插画用于观察构图与排版，全部标为 G 安全评级。作品、编号与人气排序为演示数据，不代表真实 Danbooru 条目。本原型不请求 Danbooru API。

收藏和偏好分别使用 `danbooru-pexels-prototype-favorites-v1`、`danbooru-pexels-prototype-preferences-v1` 存储，与正式页面的数据独立。浏览器禁止存储时仍可在当前会话操作。

## 已完成的检查

- JavaScript 语法检查、全部 SVG 解析检查。
- 浏览器验证：多标签搜索、比例与评级筛选、无结果提示、收藏/取消、收藏空状态、大图切换、密度与标题开关。
- 桌面及 390 像素宽手机布局视觉检查。

正式入口 `../../index.html` 现已采用此设计方向，并接回真实检索、收藏和图片预览逻辑。本目录保留最初的独立设计原型，示例数据和偏好不会影响正式页面。
