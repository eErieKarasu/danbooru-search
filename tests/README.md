# 浏览器回归

在仓库根目录运行：

```bash
python3 tests/check_static.py
python3 tests/preview_server.py
```

打开 http://127.0.0.1:4174/ 。该服务只绑定本机，并只在响应 JavaScript 时将 Danbooru 地址替换为本机固定数据接口，不修改正式源码。测试端口使用独立的浏览器存储，测试图片引用设计原型的本地插画。正式站点仍直连 Danbooru。

回归步骤（新浏览器存储、默认全部评级）：

1. 首页显示 12 张作品；舒适/紧凑/宽松会改变列数。手机保持 2/2/1 列。
2. 搜索 `scenery sky ocean`，按一次回车显示 2 张。前两个标签由测试接口处理，第三个标签由正式客户端本地过滤。
3. 打开 #910002，收藏后方向键切到 #910008；关闭、进入收藏、刷新后仍保留收藏。取消后显示收藏空状态。
4. 首页筛选 G 显示 `6 / 12 张`，叠加横图显示 `2 / 12 张`。再选超清，显示筛选空状态；清除筛选恢复 12 张。
5. 使用 Tab、方向键、Home/End、Enter 和 Esc 操作筛选菜单。滚动页面时菜单跟随触发器。
6. 设置加载 50 张、默认 G、紧凑布局、隐藏作品信息，保存并刷新；应保留偏好，显示 6 张 G 作品。
7. 搜索 `fixture_slow`，点击停止；取消请求后界面立即退出加载状态。搜索中清空标签后，旧请求不应覆盖空状态。
8. 搜索 `fixture_empty` 显示无结果；搜索 `fixture_error` 等重试结束后显示错误与重试入口。点击重试会重新加载，仍可停止。
9. 在设置中将默认评级恢复为全部，保存并刷新。#910012 的图片故意返回 404；卡片显示失败文案，预览也显示错误说明，原作品链接仍可使用。
10. 预览中的标签可发起新搜索；关闭弹窗不会把新结果滚回原来的位置。

另外检查 390px、320px 窄屏下的搜索标签换行、筛选菜单位置、弹窗滚动和横向溢出。网络请求和图片真实跨域加载需使用普通静态服务单独验证，不由固定数据测试替代。

测试服务提供 `http://127.0.0.1:4174/__mobile`（390px）和 `http://127.0.0.1:4174/__mobile?width=320` 的同源 iframe 视图，便于窄屏检查。
